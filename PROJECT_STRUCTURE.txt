│   ├── requirements.txt        # Production dependencies

│   └── Makefile                # Convenient automation commands
│
├── Documentation

│   ├── QUICKSTART.md           # Quick reference guide

│   └── utils/                  # Shared utility modules

    └── tests/
        ├── __init__.py

Key Components:
---------------

1. UTILITY FUNCTIONS (utils/)
   - read_input()         : Read entire input as string
   - read_input_lines()   : Read input as list of lines
   - read_input_numbers() : Read input as list of integers
   - read_input_grid()    : Read input as 2D grid
   - chunks()             : Split iterable into chunks
   - manhattan_distance() : Calculate Manhattan distance
   - neighbors_4()        : Get 4 orthogonal neighbors
   - neighbors_8()        : Get 8 neighbors (with diagonals)

2. WORKFLOW TOOLS
   - create_day.py        : Creates new day folder with template
   - Makefile             : Common commands (test, lint, format, etc.)

3. CODE QUALITY
   - pytest               : Testing framework
   - black                : Code formatter (100 char line length)
   - flake8               : Linter

Usage Pattern:
--------------

1. Create new day:     make day DAY=1
2. Add puzzle input:   Edit day01/input.txt
3. Implement:          Edit day01/solution.py
4. Run:                python -m day01.solution
5. Test:               make test
6. Format/Lint:        make format && make lint
